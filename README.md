
# Data Analytics Portfolio

This repository showcases my practical projects using SQL Server and Microsoft Power BI, focusing on data preparation, analytical reporting, and interactive dashboard development.

1. Banking Applications & Operational Error Analysis

Tools: SQL Server, Power BI, DAX, Power Query

This project explores banking application data and operational errors to support analytical reporting and decision-making.

Key Features:
- Integrated multiple SQL tables using JOINs and CTEs.
- Used window functions to analyze application amounts, interest rates, and intervals between customer applications.
- Segmented customers by age, income, and application status.
- Created a rule-based risk classification for analytical purposes.
- Built an interactive Power BI dashboard to monitor application trends, customer segments, and operational errors.

- `bank_application_analysis.sql.`
- `Bank app report.pbix`

 2. Online Ordering Data Analysis
